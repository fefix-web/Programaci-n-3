## Descripción del Proyecto
**SmileCare** es una aplicación web desarrollada en Python con Flask diseñada para optimizar la gestión de citas médicas y el control de pacientes en clínicas dentales locales. Permite agendar consultas de forma organizada, evitar el cruce de horarios y visualizar la agenda diaria de manera rápida y sencilla.
